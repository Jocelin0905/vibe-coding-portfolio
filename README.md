# Things I Wish Existed

A mobile-first portfolio for Jocelin’s shipped products.

## Stack

- React
- TypeScript
- Vite
- React Router
- Native CSS
- Vitest and React Testing Library

## Local development

```powershell
pnpm install
pnpm dev
```

## Verification

```powershell
pnpm test
pnpm build
```

The production deployment uses `BrowserRouter` with the SPA rewrite in `vercel.json`.
